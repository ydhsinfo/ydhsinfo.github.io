데이터 압축이란?

What is Data Compression?

데이터 압축의 정의

데이터 압축은 한정된 저장 공간에 데이터를 효율적으로 기록하기 위한 기술입니다. 원래의 데이터를 더 적은 비트(bit)로 표현하여 저장 공간을 절약하고, 네트워크 전송 시 속도를 향상시킵니다.

데이터 압축의 장점

저장 공간 절약

동일한 저장 장치에 더 많은 데이터를 보관할 수 있어 비용을 절감합니다.

전송 속도 향상

네트워크를 통해 데이터를 전송할 때 용량이 줄어들어 더 빠르게 전달됩니다.

디지털 탄소 중립

데이터 전송량 감소로 서버 부하와 에너지 소비를 줄여 탄소 중립 실천에 기여합니다.

인코딩과 디코딩

Encoding & Decoding

인코딩 (Encoding)

데이터 압축 과정

데이터를 더 적은 비트로 변환하는 과정입니다.

  • 원본 데이터에서 반복되는 패턴을 찾아 효율적으로 표현
  • 불필요하거나 중복된 정보를 제거하여 크기를 줄임

디코딩 (Decoding)

데이터 복원 과정

인코딩된 압축 데이터를 원래 형태로 복원하는 과정입니다.

  • 압축된 데이터를 원래의 형태로 되돌리는 역과정
  • 압축 방식에 따라 원본과 동일하거나 유사하게 복원

데이터 압축 처리 흐름

입력 원본 데이터
인코딩 압축 변환
저장 및 전송 압축 상태
디코딩 복원 변환
출력 복원 데이터
처리 흐름 설명

원본 데이터를 인코딩(압축)하여 저장하거나 전송한 뒤, 필요할 때 디코딩(복원)하여 사용합니다. 압축 방식에 따라 출력 데이터가 원본과 동일할 수도, 다를 수도 있습니다.

손실 압축 vs 비손실 압축

Lossy vs Lossless Compression

압축 방식은 데이터 유실 여부에 따라 손실 압축과 비손실 압축으로 나뉩니다.

손실 압축

Lossy Compression

입력 데이터 ≠ 출력 데이터

복원했을 때 데이터가 달라집니다. 사람이 인지하기 어려운 일부 정보를 제거하여 높은 압축률을 달성합니다.

  • 높은 압축률로 파일 크기 대폭 감소
  • 멀티미디어(이미지, 음악, 동영상)에 적합
  • 원본 데이터의 완벽한 복원 불가능
JPEG MP3 MP4 H.264

비손실 압축

Lossless Compression

입력 데이터 = 출력 데이터

복원했을 때 입력 데이터와 출력 데이터가 같습니다. 원본 데이터를 완벽하게 되살릴 수 있습니다.

  • 원본 데이터의 완벽한 복원 가능
  • 정확성이 중요한 데이터에 적합
  • 압축률이 상대적으로 낮음
ZIP PNG FLAC 텍스트 파일

손실 vs 비손실 압축 비교

구분 손실 압축 비손실 압축
복원 결과 원본과 다르게 복원 (일부 정보 손실) 원본과 동일하게 복원
압축률 상대적으로 높음 상대적으로 낮음
적합한 용도 사진, 음악, 동영상 등 사람의 감각으로 인지하는 미디어 텍스트, 소스 코드, 의료 이미지 등 정확성이 중요한 데이터
대표 형식 JPEG, MP3, MP4, AAC ZIP, PNG, FLAC, GIF
핵심 원리 인간이 인지하기 어려운 정보 제거 반복 패턴 제거, 통계적 부호화

쉽게 이해하기

손실 압축은 그림을 축소해서 보관하는 것과 같아서, 다시 확대하면 원래보다 흐릿해질 수 있습니다. 반면 비손실 압축은 책을 요약본으로 만든 뒤, 다시 원래의 책으로 완벽하게 복원하는 것과 같습니다.

핵심 정리

데이터 압축의 개념

  • 한정된 저장 공간에 데이터를 효율적으로 기록하는 기술
  • 인코딩(압축)과 디코딩(복원)의 과정으로 구성
  • 저장 공간 절약, 전송 속도 향상, 탄소 중립 실천

압축의 종류

  • 손실 압축: 일부 정보 제거, 높은 압축률 (JPEG, MP3)
  • 비손실 압축: 원본과 동일하게 복원 (ZIP, PNG, FLAC)
  • 용도에 따라 적절한 압축 방식을 선택하는 것이 중요

1

손실 압축 대표 형식

손실 압축은 사람이 인지하기 어려운 정보를 제거해 파일 크기를 크게 줄입니다. 아래는 미디어 유형별 대표 형식입니다.

이미지
.jpg / .jpeg

JPEG

사진·웹 이미지에 가장 널리 쓰임. 압축률 조절 가능. 반복 저장 시 화질 저하 누적

.webp

WebP (손실 모드)

Google 개발. JPEG 대비 25~35% 더 작은 크기. 웹 최적화 포맷

.heic

HEIC

Apple 기기 기본 포맷. JPEG 동일 화질에서 절반 크기

오디오
.mp3

MP3

가장 범용적인 오디오 포맷. 사람이 인지하기 어려운 주파수 제거

.aac

AAC

MP3 후계 포맷. 같은 크기에서 더 높은 음질. 스마트폰·스트리밍 표준

.ogg

OGG Vorbis

오픈소스 포맷. 게임·웹에서 자주 사용

동영상
.mp4

MP4 (H.264)

전 세계 표준 동영상 포맷. 유튜브·SNS 업로드에 기본 사용

.mp4 / .mkv

H.265 / HEVC

H.264 대비 절반 용량에 동일 화질. 4K·8K 영상에 사용

.avi / .wmv

AVI / WMV

과거 Windows 표준 포맷. 현재는 MP4로 대체되는 추세

2

비손실 압축 대표 형식

비손실 압축은 원본 데이터를 완벽하게 복원할 수 있어 정확성이 중요한 파일에 사용됩니다.

이미지
.png

PNG

투명 배경 지원. 반복 저장해도 화질 손실 없음. 로고·아이콘·스크린샷에 적합

.gif

GIF

256색 제한이지만 비손실. 애니메이션 지원으로 웹 밈에 활용

.tiff / .bmp

TIFF / BMP

의료·인쇄 분야에서 원본 화질 보존 목적으로 사용. 파일 크기가 매우 큼

오디오
.flac

FLAC

CD 음질 그대로 압축. 오디오파일이 선호하는 고음질 포맷

.wav

WAV

비압축 원본 오디오. 영상 편집·음악 제작 작업 파일에 사용

.aiff

AIFF

Apple의 비손실 오디오 포맷. WAV의 Mac 버전

일반 파일 압축
.zip

ZIP

가장 범용적인 압축 포맷. Windows·Mac 모두 기본 지원

.rar

RAR

ZIP보다 높은 압축률. 분할 압축·암호화 기능 지원

.7z / .gz

7-Zip / GZIP

7-Zip은 오픈소스 고압축. GZIP은 Linux 서버 표준 압축

3

알아두면 좋은 파일 확장자

파일 확장자는 파일의 종류와 용도를 나타냅니다. 같은 데이터라도 확장자에 따라 압축 방식·호환성·용도가 달라지므로, 상황에 맞는 형식을 선택하는 것이 중요합니다.

문서
  • .pdf 어디서나 동일하게 보이는 문서 표준
  • .docx MS Word 문서 (XML 기반 비손실)
  • .xlsx MS Excel 스프레드시트
  • .pptx MS PowerPoint 프레젠테이션
  • .hwp 한컴오피스 한글. 한국 공문서 표준
  • .txt 순수 텍스트. 가장 가볍고 범용적
이미지
  • .jpg 사진용 손실 압축. 인터넷 표준
  • .png 투명 배경 지원 비손실. 로고·아이콘
  • .gif 256색 비손실. 애니메이션 지원
  • .svg 벡터 그래픽. 크기 변경해도 깨지지 않음
  • .webp 웹 최적화 차세대 포맷 (손실·비손실 모두)
  • .raw 카메라 원본 데이터. 비압축 고화질
오디오 / 동영상
  • .mp3 손실 오디오. 가장 범용적인 음악 포맷
  • .flac 비손실 고음질 오디오
  • .wav 비압축 원본 오디오. 편집 작업용
  • .mp4 손실 동영상 세계 표준. 유튜브·SNS
  • .mkv 다중 트랙 지원 컨테이너. 자막 내장 가능
  • .mov Apple QuickTime 동영상. 고화질 편집용
프로그래밍
  • .py Python 소스 코드. AI·데이터 분야 표준
  • .java Java 소스 코드. 객체지향 프로그래밍
  • .c / .cpp C/C++ 소스. 시스템·임베디드 프로그래밍
  • .html 웹 페이지 구조 정의 언어
  • .css 웹 페이지 스타일(디자인) 정의
  • .js JavaScript. 웹 동작·인터랙션 처리
실행 파일 / 데이터
  • .exe Windows 실행 파일
  • .apk Android 앱 설치 파일
  • .ipa iOS 앱 설치 파일
  • .json 구조화 데이터 교환 표준. API·설정 파일
  • .csv 쉼표 구분 데이터. 엑셀·데이터 분석 호환
  • .xml 태그 기반 구조화 데이터. 문서·설정 교환
압축 파일
  • .zip 가장 범용적 비손실 압축. 기본 내장 지원
  • .rar 고압축률. 분할 압축·암호화 지원
  • .7z 오픈소스 고압축. ZIP보다 높은 압축률
  • .gz Linux/Mac 표준 압축. 서버 파일 전송
  • .tar.gz 여러 파일 묶음(tar) + GZIP 압축 조합
  • .iso CD/DVD 디스크 이미지 파일

상황별 포맷 선택 팁

웹에 사진 올리기 → .jpg 또는 .webp (작은 용량)
투명 배경 이미지 → .png (비손실, 투명 지원)
음악 저장·감상 → .mp3 (범용) 또는 .flac (고음질)
파일 묶어 전송 → .zip (호환성) 또는 .7z (고압축)
의료·출판 이미지 → .tiff 또는 .png (원본 보존 필수)
동영상 공유 → .mp4 H.264 (가장 넓은 호환성)
