WAV 파일

Waveform Audio File Format

WAV 파일이란?

WAV(Waveform Audio)는 웨이브 방식의 디지털 신호를 압축하지 않은 무압축 파일로, 확장자는 .wav입니다. 원본 소리 데이터를 그대로 저장하기 때문에 음질이 우수하지만 파일 크기가 큽니다.

아날로그 → 디지털 변환 과정

아날로그 소리 신호를 디지털로 변환하려면 다음 세 단계를 거칩니다.

핵심 용어 주파수: 1초당 샘플링 횟수 (Hz)

소리 압축 파일

Audio Compression Formats

WAV 파일은 고음질이지만 용량이 매우 크기 때문에 다양한 압축 기술이 개발되었습니다. 소리 압축 방식은 비손실 압축과 손실 압축으로 나뉩니다.

FLAC

Free Lossless Audio Codec

비손실
  • 무음 구간과 반복 구간을 더 적은 비트로 표현
  • 원음 파형의 예측 수식과 실제 차이만 저장
  • 압축 해제 시 원본 복원 가능
파일 크기 예시 4.01 MB

MP3

MPEG-1 Audio Layer 3

손실
  • 사람이 잘 듣지 못하는 대역의 신호를 제거
  • 비트 전송률(bitrate)로 음질 조절 가능
  • 가장 널리 사용되는 음악 포맷
파일 크기 예시 361 KB

AAC

Advanced Audio Coding

손실
  • MP3와 같은 방식으로 압축
  • 동일 비트 전송률에서 MP3보다 음질이 더 좋음
  • Apple Music 등 스트리밍 서비스에서 활용
파일 크기 예시 366 KB

핵심 용어 정리

Key Terms

표본화 Sampling

아날로그 소리 파형을 일정 간격으로 나누어 신호의 값을 측정하는 과정

양자화 Quantization

측정된 소리의 크기를 가까운 정숫값으로 표현하는 과정

부호화 Encoding

각 정숫값을 0과 1의 이진수(디지털값)로 표현하는 과정

비트 전송률 Bitrate

1초당 전송되는 비트 수. 높을수록 음질이 좋지만 파일 크기가 커짐

주파수 Frequency

1초당 파형이 반복되는 횟수(Hz). 소리의 높낮이를 결정

진폭 Amplitude

소리 파형의 크기(세기). 진폭이 클수록 소리가 크게 들림

Summary

  • 무압축 오디오 파일 (.wav 확장자)
  • 변환 과정: 표본화 → 양자화 → 부호화
  • CD 음질 1초 = 약 1,411,200 bit (≒ 0.16MB)

소리 압축 파일

  • FLAC: 비손실 압축, 원본 복원 가능
  • MP3: 손실 압축, 사람이 듣지 못하는 대역 제거
  • AAC: 손실 압축, MP3보다 음질 우수

소리의 물리적 성질

주파수, 각주파수, 주기, 위상, 진폭

소리는 공기의 진동이 파동으로 전달되는 현상입니다. 이 파동을 수학적으로 표현하면 아래와 같은 성질들로 설명할 수 있습니다. 각 개념을 일상적인 비유와 함께 알아봅시다.

주파수 (Frequency)

단위: Hz (헤르츠) — 1초에 몇 번 진동하는가

주파수는 1초 동안 파동이 몇 번 반복되는지를 나타냅니다. 단위는 Hz(헤르츠)이며, 주파수가 높을수록 높은 음, 낮을수록 낮은 음이 됩니다.

비유로 이해하기

놀이공원의 바이킹을 떠올려 보세요. 1초에 1번 왕복하면 1Hz, 2번 왕복하면 2Hz입니다. 바이킹이 빠르게 왕복할수록(주파수가 높을수록) 더 높은 소리에 해당합니다.

주파수 비교

낮은 음 (100Hz) 느린 진동
높은 음 (1000Hz) 빠른 진동

사람이 들을 수 있는 범위는 약 20Hz ~ 20,000Hz입니다. 피아노 가운데 '라(A4)' 음은 440Hz입니다.

주기 (Period)

단위: 초(s) — 파동 1회 반복에 걸리는 시간

주기는 파동이 한 번 완전히 반복되는 데 걸리는 시간입니다. 주파수와 주기는 역수 관계입니다.

T = 1 / f      f = 1 / T

T: 주기(초), f: 주파수(Hz)

440Hz

주기 = 1/440 ≈ 0.00227초

100Hz

주기 = 1/100 = 0.01초

비유로 이해하기

학교 운동장을 한 바퀴 도는 데 걸리는 시간이 주기입니다. 빨리 달리는 사람(높은 주파수)은 한 바퀴 시간이 짧고(짧은 주기), 천천히 걷는 사람(낮은 주파수)은 한 바퀴 시간이 깁니다(긴 주기).

진폭 (Amplitude)

파동의 높이 — 소리의 크기(세기)를 결정

진폭은 파동의 중심에서 꼭대기(또는 골)까지의 거리입니다. 진폭이 클수록 큰 소리, 작을수록 작은 소리입니다.

비유로 이해하기

수영장에서 물장구를 칠 때, 세게 치면 파도가 크고(큰 진폭 = 큰 소리), 살짝 치면 잔물결만 생깁니다(작은 진폭 = 작은 소리).

진폭 비교

큰 소리 (큰 진폭)

작은 소리 (작은 진폭)

각주파수 (Angular Frequency)

단위: rad/s — 1초에 몇 라디안 회전하는가

각주파수(ω)는 주파수를 원운동의 각도로 표현한 것입니다. 파동 1회 반복 = 원 1바퀴(360° = 2π 라디안)이므로, 주파수에 2π를 곱하면 됩니다.

ω = 2π × f

ω: 각주파수(rad/s), f: 주파수(Hz), π ≈ 3.14159

예) 440Hz의 각주파수 = 2 × 3.14159 × 440 ≈ 2,764 rad/s

비유로 이해하기

시계 초침이 1초에 몇 바퀴 도는지가 주파수라면, 1초에 몇 도(각도) 도는지가 각주파수입니다. 같은 회전이지만 각도로 표현하면 수학적 계산이 편리해집니다.

왜 각주파수를 쓸까? 소리 파형을 수학식으로 쓸 때 sin(ωt + φ)처럼 각주파수를 사용하면 공식이 깔끔해지기 때문입니다.

위상 (Phase)

단위: 라디안(rad) 또는 도(°) — 파동의 시작 위치

위상(φ)은 파동이 어느 지점에서 시작하는지를 나타냅니다. 같은 주파수, 같은 진폭의 두 파동도 시작 위치가 다르면 다른 소리가 됩니다.

같은 주파수, 다른 위상의 파동

위상 = 0° (기준)

위상 = 180° (반 바퀴 밀림)

위상이 180° 다른 두 파동을 합치면 서로 상쇄되어 소리가 사라집니다 → 노이즈 캔슬링의 원리!

비유로 이해하기

두 사람이 같은 속도로 그네를 타는데, 한 사람은 앞에 있을 때 다른 사람은 뒤에 있다면? 둘은 같은 주파수(속도)지만 위상이 다른것입니다.

악기 튜닝

기타나 피아노를 조율할 때 기준음 440Hz(라)의 주파수에 맞춥니다. 튜너 앱은 소리의 주파수를 분석하여 정확한 음을 찾아줍니다.

음량 조절 (볼륨)

스마트폰이나 스피커의 볼륨을 올리면 소리 파동의 진폭이 커집니다. 주파수(음의 높이)는 그대로이고, 진폭만 변하는 것입니다.

이퀄라이저 (EQ)

음악 앱의 이퀄라이저는 주파수 대역별 진폭을 조절합니다. 저음(낮은 주파수)을 강조하면 베이스가, 고음(높은 주파수)을 올리면 선명한 소리가 됩니다.

초음파 검사

병원의 초음파 검사는 사람이 들을 수 없는 높은 주파수(2~18MHz)의 소리를 몸 안에 보내고, 반사되는 파동의 위상과 진폭 변화를 분석하여 영상을 만듭니다.

지진파 분석

지진파도 파동입니다. 지진의 주기와 진폭을 분석하여 규모와 진원지를 파악합니다. 건물 내진설계에도 주파수 분석이 핵심적으로 사용됩니다.

소리 압축 원리

FLAC, MP3, AAC는 어떻게 파일 크기를 줄일까?

FLAC 압축 원리

비손실 압축 — 선형 예측 + 라이스 부호화

FLAC은 소리 데이터를 하나도 버리지 않으면서 원본의 약 50~70% 크기로 줄입니다. 크게 두 단계를 거칩니다.

1 선형 예측 — 다음 값을 예측하고 차이만 저장

소리 파형은 부드럽게 이어지기 때문에, 앞의 값들로 다음 값을 꽤 정확히 예측할 수 있습니다. FLAC은 예측값과 실제값의 차이(잔차)만 저장합니다. 이 잔차는 대부분 0에 가까운 작은 수입니다.

동작 예시

실제 샘플: 100, 102, 105, 103, 101

예측값:     —,  100, 104, 108, 101

잔차:      100,  +2,  +1,  -5,   0 ← 작은 수들!

2 라이스(Rice) 부호화 — 작은 수를 짧은 코드로

잔차 값은 대부분 0 근처의 작은 수이므로, 작은 수에 짧은 코드를 배정하는 라이스 부호화로 효율적으로 압축합니다. 허프만 코딩과 비슷한 원리이지만, 정수에 특화된 방식입니다.

핵심 정리: FLAC은 ①앞 샘플로 다음 값을 예측하고 차이(잔차)만 기록 → ②잔차를 라이스 부호화로 압축합니다. 어떤 정보도 버리지 않으므로 압축을 풀면 원본과 100% 동일합니다.

MP3 압축 원리

손실 압축 — 심리음향 모델 + MDCT + 허프만 코딩

MP3는 "사람의 귀가 듣지 못하는 소리를 과감히 제거한다"는 아이디어에 기반합니다. JPEG가 눈이 못 보는 것을 제거하듯, MP3는 귀가 못 듣는 것을 제거합니다.

1 심리음향 모델 — 귀가 못 듣는 소리 찾기

사람의 청각에는 재미있는 특성이 있습니다. 이것을 이용하여 "어차피 안 들리는" 소리를 찾아냅니다.

절대 가청 한계

사람은 약 20Hz~20,000Hz 범위만 들을 수 있습니다. 이 범위 밖의 소리는 아무리 크게 틀어도 안 들리므로 제거합니다. 또한 매우 작은 소리도 들리지 않으므로 제거합니다.

마스킹 효과

큰 소리 옆의 작은 소리는 들리지 않습니다. 예를 들어, 드럼이 "쾅!" 하는 순간 옆의 작은 기타 소리는 안 들립니다. 이렇게 가려지는(마스킹된) 소리도 제거합니다.

2 MDCT 변환 — 소리를 주파수 성분으로 분해

소리를 짧은 구간(약 0.02초)으로 잘라, 각 구간에 포함된 주파수 성분을 분석합니다. "이 구간에는 440Hz 성분이 크고, 15,000Hz 성분은 작다" 같은 정보를 얻습니다. JPEG의 DCT와 비슷한 원리입니다.

3 양자화 — 안 들리는 성분 제거 (여기서 손실 발생!)

심리음향 모델이 "이 주파수 성분은 안 들린다"고 판단하면, 해당 값을 0으로 만들거나 정밀도를 낮춥니다. 비트 전송률(bitrate)이 높을수록 적게 버리고(고음질), 낮을수록 많이 버립니다(저음질, 작은 파일).

4 허프만 코딩 — 남은 데이터 최종 압축

양자화 후 0이 많아진 데이터를 허프만 코딩으로 최종 압축합니다. 자주 나오는 값(특히 0)에 짧은 코드를 배정합니다. 이 단계는 비손실입니다.

핵심 정리: MP3는 ①사람이 못 듣는 소리(가청 범위 밖, 마스킹된 소리)를 찾아내고 → ②소리를 주파수 성분으로 분해하고 → ③안 들리는 성분을 제거/축소하고 → ④남은 데이터를 허프만 코딩으로 압축합니다. 원본의 약 1/10 크기로 줄일 수 있습니다.

AAC 압축 원리

손실 압축 — MP3의 개선판

AAC는 MP3의 후속 규격으로, 기본 원리는 동일하지만 각 단계가 더 정교하게 개선되었습니다. 같은 비트 전송률에서 MP3보다 더 좋은 음질을 제공합니다.

MP3 대비 AAC의 개선점

더 넓은 주파수 처리

MP3는 최대 16kHz까지만 처리하지만, AAC는 최대 96kHz까지 처리할 수 있어 고음역 표현이 더 풍부합니다.

더 정교한 심리음향 모델

마스킹 효과를 시간축과 주파수축 모두에서 더 정밀하게 분석합니다. "진짜 안 들리는 것"만 골라 제거하므로 음질 손상이 적습니다.

유연한 블록 크기

MP3는 분석 구간 크기가 고정되어 있지만, AAC는 구간 길이를 자동 조절합니다. 급격한 변화(타악기 등)에는 짧은 구간, 부드러운 소리에는 긴 구간을 사용합니다.

향상된 엔트로피 코딩

MP3의 허프만 코딩에 더해 산술 코딩도 사용할 수 있어 최종 압축 효율이 더 높습니다.

핵심 정리: AAC는 MP3와 같은 원리(심리음향 모델 → 주파수 분해 → 양자화 → 엔트로피 코딩)를 사용하되, 각 단계가 더 정교하여 같은 파일 크기에서 더 좋은 음질을 제공합니다. Apple Music, YouTube 등 주요 서비스에서 표준으로 사용됩니다.
