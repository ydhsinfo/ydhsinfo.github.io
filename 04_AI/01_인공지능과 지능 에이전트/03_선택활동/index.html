에이전트 작동 사이클

Agent Operation Cycle

탐색 방법

지능 에이전트는 인식 - 학습 - 추론 - 행동의 사이클을 반복합니다. 아래 다이어그램에서 각 단계를 클릭하여 상세 내용을 확인하세요.

각 단계를 클릭하여 탐색하세요

왼쪽 다이어그램에서 단계를 클릭하세요

인식 (Perceive)

센서를 통해 환경의 정보를 수집하는 단계입니다. 에이전트가 세상을 이해하는 첫 번째 단계입니다.

자율주행차: 카메라로 도로 상황 촬영
AI 스피커: 마이크로 사용자 음성 수집
로봇 청소기: 적외선 센서로 장애물 감지

학습 (Learn)

수집된 데이터에서 패턴을 발견하고 지식을 축적하는 단계입니다. 경험을 통해 점점 더 나은 판단을 할 수 있게 됩니다.

수많은 도로 영상에서 신호등 패턴 학습
대화 데이터에서 자연어 문맥 이해 학습
청소 이력으로 최적 경로 패턴 학습

추론 (Reason)

학습된 지식을 바탕으로 현재 상황을 분석하고 최선의 행동을 결정하는 단계입니다.

앞차가 멈추면 브레이크를 밟아야 한다고 판단
"노래 틀어줘" 의도를 파악하고 음악 재생 결정
장애물 감지 시 우회 경로 계산

행동 (Act)

추론 결과를 바탕으로 구동기를 통해 환경에 실제 행동을 수행하는 단계입니다. 행동의 결과는 다시 인식 단계로 이어집니다.

브레이크를 밟아 차량 감속
스피커를 통해 음악 재생 시작
모터를 회전시켜 방향 전환

핵심 정리

Key Summary

지능 에이전트 구성

  • 센서로 환경을 인식
  • 인공지능으로 학습/추론하여 판단
  • 구동기로 환경에 행동

지능 에이전트 특성

  • 자율성 - 스스로 판단하고 행동
  • 목적성 - 목표를 위해 행동
  • 적응성 - 환경 변화에 적응
  • 사회성 - 다른 에이전트와 협력
