특징 설명

인터넷만 있으면 어디서든 파일에 접근 가능하고 링크로 여러 사람과 동시에 공유할 수 있다
물리적 케이블 연결로 안정적이며 빠른 속도를 제공하지만 이동이 불편하다
스마트폰이나 노트북의 화면을 TV에 실시간으로 동일하게 출력할 수 있다
근거리에서 인터넷 없이 기기 간 직접 파일을 빠르게 전송할 수 있다
별도 앱 없이 기기 간 무선으로 파일을 보낼 수 있지만 전송 속도가 느리다

D USB 메모리에 복사해서 TV에 연결

모둠 과제를 하는데, 팀원 4명이 각자 집에서 같은 문서를 동시에 편집해야 한다. 가장 좋은 방법은?
